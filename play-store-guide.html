등록 도중 막히지 않도록, 아래 4가지가 손에 있는지 먼저 확인하세요.

  • Google 계정 — Play 개발자 등록에 쓸 계정 (개인/회사 무관, 이후 변경 어려우니 신중히).

  • 빌드 환경 — 이 맥에서 flutter build appbundle가 되는 상태 (이미 검증됨).
순서를 왜 이렇게?

개인정보방침 URL(1단계)과 SHA 등록(6단계)은 콘솔 입력 중 "지금 필요한데 없네"로 흐름을 끊는 대표 항목이라 먼저 처리합니다. 계정·앱 생성은 그다음입니다.

1

개인정보처리방침을 공개 URL로 게시

소요 15–30분담당: 당신필수 · 없으면 심사 거부

Play는 인터넷에서 누구나 열 수 있는 방침 URL을 요구합니다. 초안은 이미 docs/privacy-policy.md에 있으니, 공개 웹페이지로만 올리면 됩니다. 가장 쉬운 3가지:

  1. GitHub Pages — repo Settings → Pages에서 docs/ 폴더를 소스로 지정하면 https://<아이디>.github.io/LinkNote/privacy-policy 형태로 바로 게시. (repo가 이미 있으니 가장 빠름)
  2. Notion — 방침 내용을 페이지에 붙여넣고 우상단 공유 → 웹에 게시. 생성된 공개 링크 사용.
  3. 전용 도메인 — 예: privacy.linknote.app (도메인이 있다면).

게시 전에 딱 하나 고칠 것

방침 안의 문의처 이메일이 아직 placeholder(support@kaywalker.app)입니다. 실제로 받을 수 있는 주소로 바꾸세요 — 이 앱의 문의처는 rikygak@gmail.com입니다. 이 이메일은 Data safety·문의 대응에 그대로 쓰입니다.

확인 방법

시크릿 창(로그아웃 상태)에서 그 URL이 열리면 통과. 로그인해야 보이면 Play가 못 읽습니다. 게시된 URL을 메모장에 복사해 두세요 — 5단계에서 붙여넣습니다.

간단한 설명 · 최대 80자

웹 링크·영상·메모를 한곳에 저장하고 태그·컬렉션·검색으로 정리하는 북마크 앱

자세한 설명 · 최대 4000자

LinkNote는 흩어진 웹 링크와 메모를 한곳에 모아 깔끔하게 정리하는 북마크 앱입니다.

■ 무엇이든 빠르게 저장
- 다른 앱에서 '공유'만 누르면 링크가 곧장 LinkNote에 저장됩니다.
- 웹 링크, 유튜브 영상, 아티클, 짧은 메모까지 한 공간에 모읍니다.
- 링크를 붙여넣으면 제목·미리보기를 자동으로 가져옵니다.

■ 내 방식대로 정리
- 태그와 컬렉션으로 주제별 분류.
- 즐겨찾기로 자주 보는 링크를 위로.
- 강력한 검색으로 저장한 모든 것을 즉시 찾기 (태그·날짜·즐겨찾기 필터 지원).

■ 읽은 기록 한눈에
- 링크별로 몇 번 열어봤는지, 마지막으로 언제 봤는지 표시됩니다.

■ 가볍게 공유
- 컬렉션을 공개로 전환하면 딥링크 하나로 읽기 전용 공유.
- 받은 사람은 내 데이터를 수정·삭제할 수 없어 안전합니다.

■ 눈이 편한 디자인
- 라이트/다크 모드 모두 정성껏 다듬은 화면.
- 오프라인에서도 저장한 내용을 빠르게 열람.

지금 LinkNote로 흩어진 링크를 깔끔하게 정리해 보세요.

절대 잊지 말 것

이걸 어기면 되돌리기가 매우 어렵습니다

1 · 키스토어 분실 = 앱 업데이트 영구 불가

android/linknote-release.keystore 파일과 비밀번호를 최소 2곳(암호화 백업 + 오프라인 USB)에 보관하세요. 이 업로드 키를 잃으면 같은 앱을 다시는 업데이트할 수 없습니다. git에는 절대 커밋 금지(이미 gitignore됨).

2 · 첫 업로드 후 App Signing SHA를 Firebase에 추가

Play App Signing이 켜지면 실제 배포 서명 키는 Google이 관리합니다. Console 앱 서명(App signing) 화면의 SHA-1/256을 Firebase에도 반드시 추가 등록하세요. 안 하면 배포판에서 로그인 등이 조용히 실패합니다.
