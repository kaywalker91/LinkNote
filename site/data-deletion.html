01 계정을 유지한 채 데이터 삭제 (앱 내 직접)

로그인 상태에서 앱 안에서 언제든지 직접 삭제할 수 있으며, 즉시 반영됩니다.

  1. 링크 삭제 — 저장한 링크를 열어 삭제하면 해당 링크와 관련 정보(제목·메모·태그 연결)가 제거됩니다.
  2. 컬렉션 삭제 — 컬렉션 상세 화면의 삭제(Delete)로 컬렉션을 제거합니다.

02 계정과 모든 데이터 완전 삭제 요청

앱 내에는 계정 삭제 버튼이 없으므로, 아래 절차로 요청하면 계정과 서버에 저장된 모든 데이터를 영구 삭제합니다.
