# Daily Task Log (개발 세션 요약 일지)

LinkNote 프로젝트의 일일 개발 업무 및 세션 요약(`session.md`) 문서를 보관하는 디렉터리입니다.
문서 누적으로 인한 탐색 불편을 해소하고 프로젝트 히스토리를 체계적으로 관리하기 위해 **연월(`YYYY-MM`) 기준 폴더 분류** 체계를 따릅니다.

---

## 📁 디렉터리 구조 및 분류 체계

```
docs/daily_task_log/
├── 2026-03/         # 2026년 3월 세션 로그 (1건)
├── 2026-04/         # 2026년 4월 세션 로그 (24건)
├── 2026-05/         # 2026년 5월 세션 로그 (12건)
├── 2026-06/         # 2026년 6월 세션 로그 (1건)
├── 2026-07/         # 2026년 7월 세션 로그 (2건)
└── README.md        # 안내 및 인덱스 문서
```

### 📌 파일 명명 규칙 (Naming Convention)
신규 세션 요약 문서 생성 시 아래 기본 양식을 따르며, 해당 연월(`YYYY-MM`) 디렉터리에 생성합니다.
- **최신 명명 양식**: `YYYY-MM-DD_session.md` (예: `2026-07-27_session.md`)
- **구 명명 양식 (Session 58 이전)**: `YYYY-MM-DD_sessionNN.md` (예: `2026-05-23_session58.md`)

## 🛠️ 새 세션 로그 작성 가이드
1. 오늘 날짜 확인 후 해당 월 폴더(`docs/daily_task_log/YYYY-MM/`) 존재 여부 확인 (없으면 생성).
2. `YYYY-MM-DD_session.md` 양식으로 문서 작성.
3. 문서 필수 항목:
   - 날짜 & 세션 정보 (최신 커밋, PR 번호, 브랜치명)
   - 쉽게 읽는 개발 일지 (비개발자용 요약, 변경 이유 및 핵심 효과)
   - 오늘 작업 요약 및 변경된 파일 목록 (+X/-Y)
   - 완료된 작업 체크리스트 및 오늘의 학습 / 다음 세션 TODO
